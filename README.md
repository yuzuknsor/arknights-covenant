# 卫戍协议 · 流派图鉴

明日方舟「卫戍协议」模式攻略站——15 个流派的机制、节奏、干员分工与详情。

**线上地址**：https://yuzuknsor.github.io/arknights-covenant/

## 内容

| 模块 | 说明 |
|---|---|
| 左侧栏 | 15 个流派纵向导航，滚动自动高亮 |
| 流派卡 | 盟约徽章 + 推荐策略 + 纵深数值（层/回合、凑齐率、倍率） |
| 干员墙 | 按角色分工分四组：🟣叠层 / 🔴主C / 🟢辅助 / ⚪过渡 |
| 详情块 | 原理、节奏、BP·分队、装备、细节 |
| 头像弹窗 | 点击任一干员头像 → 等阶 + 盟约 + 完整特质文本 |

## 数据来源

- 干员 / 盟约 / 策略 / 装备数据：closure.wiki（公开 wiki）
- 战术内容：21 个 B 站攻略视频转写整理 + 本机数据复算
- 素材：142 张干员头像、161 张图标（webp）

## 技术

单页静态站，零构建依赖：`index.html` + `figures/`。原生 JS 实现侧栏高亮、角色分组、弹窗；`<900px` 时侧栏退化为顶部排列。
